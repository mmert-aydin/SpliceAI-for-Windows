SpliceAI Variant Scoring - please read before installing

WHAT THIS SETUP INSTALLS

This Setup contains SpliceAI Variant Scoring and the tools it uses:
  - SnpEff with its GRCh37 and GRCh38 RefSeq databases (MIT License)
  - Eclipse Temurin 21 Java runtime, used only to run SnpEff
    (GPLv2 with Classpath Exception)
  - NCBI MANE Select summary data (public domain, NCBI)
  - Microsoft Visual C++ runtime files, used only by this program

SPLICEAI ITSELF IS NOT INCLUDED

SpliceAI is made by Illumina, Inc. During installation, Setup downloads the
official SpliceAI 1.3.1 package directly from the Python Package Index
(pypi.org), where it is published, and checks that the file is exactly the
published one. This needs an internet connection once, during Setup only.
